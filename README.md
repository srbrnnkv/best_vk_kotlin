# best_vk_kotlin

ДЗ 1 «Работа со списком»: сетка квадратов с номерами (индекс с 0), чётные — красные, нечётные — синие.

- 3 колонки в портретной ориентации, 4 — в горизонтальной (`res/values/integers.xml` и `res/values-land/integers.xml`).
- Кнопка «+» (FAB) добавляет квадрат в конец списка; у списка есть нижний отступ под кнопку, поэтому при скролле до конца она не перекрывает квадраты.
- Количество квадратов сохраняется при повороте экрана через `onSaveInstanceState` (без файлов и SharedPreferences).
- Нет разрешения INTERNET, нет `Log`, цвета/размеры/строки вынесены в ресурсы.

Сборка: `./gradlew assembleDebug` (или Run в Android Studio).
